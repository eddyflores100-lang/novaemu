¿Qué verifica el golden?

Cada demo determinista tiene un hash FNV-1a-64 del framebuffer capturado en el frame 300 por el binario nativo. Si el WASM reproduce ese hash bit a bit, tu navegador ejecuta el mismo motor certificado.

¿Qué verifica Blargg?

Las ROMs de Shawn «blargg» Blargg son el estándar de facto para certificar CPUs GB: verifican cada instrucción con checksums CRC-32 y publican el veredicto por el puerto serie. Aquí capturamos ese mismo Passed.

¿Por qué importa el determinismo?

Un emulador no determinista no puede verificar nada: el mismo input debe producir el mismo output siempre. Dos pasadas con hashes idénticos demuestran que el pacer y el RNG no contaminan.
